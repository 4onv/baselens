# Why BaseLens

Research date **November 5, 2026, America/Chicago**. Evidence was reviewed on November 6. The research window runs from `2026-11-05T06:00:00Z` through, but excluding, `2026-11-06T06:00:00Z`.

BaseLens was selected to make an easily missed HTML behavior visible. A relative link can resolve somewhere different when a page contains `<base href>`. A small comparison tool lets someone inspect that difference using saved HTML and a page address.

## Existing alternatives

**DevToolbelt's HTML link extractor** already accepts pasted HTML and a page URL, honors a base element, and provides resolved links, metadata, filtering and exports. BaseLens's chosen emphasis is the side-by-side explanation of what the base changes, packaged for local use. This is a focused convenience claim. [DevToolbelt](https://devtoolbelt.tech/tools/extract-links-from-html)

**HTML::SimpleLinkExtor** provides base-aware extraction through a Perl library. **TBD Board** covers the proposed planning-board workflow extensively. **GNU env** supplies the central environment-filtering mechanism. These alternatives informed the scope and rejected candidates. [HTML::SimpleLinkExtor](https://github.com/nigelhorne/HTML-SimpleLinkExtor), [TBD Board](https://github.com/Camerash/tbd-board), [GNU env](https://www.gnu.org/s/coreutils/manual/html_node/env-invocation.html)

## Scope of the evidence

The HTML standard specifies that the first `base` element with an `href` supplies the document's base. A failed URL parse or a `data:` or `javascript:` scheme falls back to the document URL. Later base elements do not take over. Fragment references also resolve against the effective base. [WHATWG HTML](https://html.spec.whatwg.org/multipage/semantics.html#the-base-element), [MDN base element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/base)

The project choice rests on one concrete report, selective competitor research and dated observations. Static markup provides limited evidence about a live page. Redirects, script-created links, CSP and browsing contexts can affect actual behavior. Synthetic demonstrations illustrate the selected behavior, and the README describes the implemented coverage. This research makes no forecast of stars.
