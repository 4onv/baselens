A clear view of the static HTML

BaseLens inspects HTML a[href] and area[href] outside nested templates. It assumes scripting is enabled and ignores links and bases inside noscript. A <frameset marker is conservatively rejected, even inside a comment or quoted example. Link labels are limited to 1,000 characters.

“Changed” compares with resolution from the page URL alone. “Cross-origin” compares HTTP(S) destinations with the page origin. Invalid first-base handling can vary by browser. Runtime changes, Content Security Policy, redirects and link availability need separate checks. A cross-origin destination can be intentional.
